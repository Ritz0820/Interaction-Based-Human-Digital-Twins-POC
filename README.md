# Interactive Unity & Python Dissertation System

 
This repository contains the source code for a Master's dissertation research project, featuring a Unity (C#) front-end interface integrated with a Python backend and analytics dashboard.

 
## 📁 Repository Structure
* **`Assets/Scripts/`**: Unity C# scripts handling user interactions, UI, and backend communication.
* **`app.py`**: Python backend server managing data processing and API logic.
* **`dashboard.py`**: Analytics dashboard for visualizing user session data.
* **`interactions.db`**: SQLite database storing interaction logs.
* **`strategies.json`**: System configuration parameters.

 
## 📝 Note on Assets
Raw 3D binary assets (avatar models, textures, and environmental meshes) are excluded to optimize repository size. Full computational logic is preserved in the C# scripts.
